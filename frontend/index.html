About This Project

This is a Retrieval-Augmented Generation (RAG) application that uses natural language processing to answer questions about airline flight data. Ask about flight schedules, airlines, routes, departure times, and delays in plain English.

  • Get instant answers powered by AI
  • Your API key is stored locally in your browser only
